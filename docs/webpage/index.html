Bring your own key

Speech: OpenAI, Groq, xAI, Mistral, Gemini, Corti, or Tinfoil. Reasoning: OpenAI, Anthropic, Gemini, Groq, and the same private options. Or any OpenAI-compatible server you host.

Questions

Is my voice private?

Local models run on your machine. Audio does not leave the device unless you choose a cloud provider and supply your own key.

Do I need the internet?

Not for local dictation after the model is downloaded. Updates, optional cloud APIs, calendar sync, and first-run model downloads need a connection.

Is it free?

The app is MIT licensed. There is no license key and no subscription. Local speech and local LLMs cost nothing. Bring-your-own-key providers bill you directly if you use them.

What permissions does it need?

Microphone everywhere. Accessibility on macOS for auto-paste. Screen Recording on macOS only if you enable screen context or system-audio meeting capture. Calendar access only if you connect a calendar.

Which package should I download?

macOS: the Apple Silicon DMG, with a zip on the same card. Windows: the installer. Linux packages are not published yet.

What are the system requirements?

8 GB RAM minimum, 16 GB recommended for larger models. About 1 GB for the app, plus 75 MB–3 GB per speech model.
